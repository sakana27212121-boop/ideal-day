# 冒険の書（ideal-day）

理想を設定 → 1日を計画 → 実行 → 記録 → 分析 → 改善 → 次の日へ反映、を回す生活管理アプリ。
PC・iPhone（ホーム画面に追加）で使うWebアプリ。データはSupabaseで同期する。

## 使い方
1. 公開ページを開き、メールアドレスとパスワードで登録（確認メールのリンクを開いてからログイン）
2. 最初に「理想の1日」（起床・就寝・食事・運動・自由時間・作業できる時間・毎週の固定予定・目標）を設定
3. ホームの「つぎのクエスト（NEXT ACTION）」から作業を開始・終了。終了時に「次回どこから始めるか」を残すと、次回の開始時に表示される
4. iPhone：Safariで開き、共有ボタン →「ホーム画面に追加」

## 主な機能
- ホーム：今日の状態（睡眠・起床・食事・運動・習慣）、NEXT ACTION、時間割、今日の改善ポイント
- 作業セッション：開始・一時停止・再開・中断・終了の時刻と実作業時間を自動記録。引き継ぎ（前回の結果・残り・次に始める場所）
- 予定：理想と毎週の固定予定から自動作成。タスクは締切・優先度・集中しやすい時間帯・過去の実績（見積もり補正）を考えて空き時間へ。予定より長引いた・早く終わった場合は変更を「提案」し、承認後に反映（固定予定は動かさない）
- 分析・成長：7日／4週間／90日。データ不足のときは断定しない。仮説 → 改善案 → 1週間の改善実験 → 結果の確認 → 続ける／元に戻す／別案
- AI相談：アプリ内のAI接続は見送り。期間を選んで記録（事実のみ・自由記述を含めるかは選択）を書き出し、コピーして Claude Code で相談する
- 「継続」で終えたタスクは、今日の空き時間へ入れ直す案を出す（承認後に反映・固定予定は動かさない）
- 呼び名の切替（冒険／ふつう）、オフラインでも記録でき、通信が戻ると同期

## 構成
| ファイル | 役割 |
|---|---|
| `index.html` | 入口 |
| `js/app.js` | ログイン・画面切替・操作 |
| `js/views.js` | 画面の描画 |
| `js/domain.js` | 生活・タスク・予定・分析のルール |
| `js/db.js` | 保存と同期（保存処理はここに集約） |
| `js/util.js` / `js/config.js` | 道具 / 接続先（publishableキーは公開前提） |
| `css/app.css` | デザイン（ドット書体＋読みやすいUD書体） |
| `sw.js` / `manifest.webmanifest` / `icons/` | オフライン対応・ホーム画面追加 |
| `vendor/` | Supabaseライブラリ、書体（DotGothic16・BIZ UDPGothic、OFL） |
| `supabase/migrations/` | データベースの定義（全表に本人のみ読み書きできるRLS） |

日付は0時で切り替わる（0時を過ぎた記録は翌日の扱い。睡眠時間は前日・当日の「寝る」から直前のものを使って計算）。

## 検証
Playwright と Chromium が入った環境で：
- `node tests/e2e.js` … PC・iPhone表示で主要操作（ログインなしの検証用モード `?local=1`）
- `node tests/sync.js` … 本物のSupabaseで2端末の同期・オフライン・権限（テスト用ユーザーを作って最後に削除。Supabase管理APIの権限が必要）
- `node tests/public.js` … 公開ページ（GitHub Pages）で最終確認：ログイン・同期・作業の開始〜終了・予定変更・オフライン起動・表示（テスト用ユーザーを作って最後に削除）
